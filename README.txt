MagicLand Status – Webseiten für Discord Developer Portal

1. In terms.html und privacy.html die fett markierten Betreiber-/Datenschutzangaben anhand des echten Bots ergänzen. Diese Vorlagen sind keine bereits vollständig geprüften Rechtstexte.
2. Ein öffentliches GitHub-Repository namens magicland-status-legal erstellen.
3. index.html, terms.html und privacy.html ins Stammverzeichnis hochladen.
4. Repository -> Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.
5. Nach Veröffentlichung die tatsächlichen Links prüfen. Typische URLs:
   https://DEIN-GITHUB-NAME.github.io/magicland-status-legal/terms.html
   https://DEIN-GITHUB-NAME.github.io/magicland-status-legal/privacy.html
6. Die beiden Links in die entsprechenden Felder im Discord Developer Portal eintragen.
